# 运行时依赖清单
#
# 本项目**零第三方运行时依赖**——只用 Python 标准库。
# 这不是偷懒，是设计约束：交付对象是政务专网里的可私有化闭源系统，
# 依赖越少，部署环境需要准备的东西越少，出问题时排查面越小。
#
#   Python >= 3.10（已在 pyproject.toml 中声明）
#   SQLite（随 Python 自带，用于只读镜像 + append-only 审计）
#
# 方案 §4.1 里那些重依赖（PostgreSQL+PostGIS / pgvector / vLLM / Ollama /
# PaddleOCR / Leaflet / MapLibre / SurveyJS）**全部做成了可替换适配器**，
# 现阶段用标准库兜底跑通，生产切换路径见 docs/design.md 第 8 节。
#
